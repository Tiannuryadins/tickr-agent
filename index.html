An agent that shows its work.

TICKR reads live reference data for Coinbase tokenized stocks from the public Tokenized Stocks API (no key required), scores each stock with published, rule-based logic — no black box — and logs every paper-trade decision onchain to a public journal on Base Sepolia testnet, with its reasoning hash and an ERC-8021 Builder Code (bc_sijyqbvn) attached. Anyone can verify any decision.

3 · Agent analysis rule-based · every signal carries its reasons

How the agent scores (published rules — audit me)
  • Freshness: NAV age < 1h → +30 · 1–6h → +15 · > 6h → forced AVOID (stale price).
  • Supply depth: total supply > 10,000 → +20 · 1,000–10,000 → +10 · thin/unknown → +0.
  • Drift vs last snapshot: NAV up > 2% → +10 · down > 2% → −10 · otherwise +0.
  • Signal: score ≥ 40 → BUY · 20–39 → HOLD · < 20 or stale/no NAV → AVOID.
  • Sizing: at most 10% of available paper cash per BUY, whole milli-shares.
  • No NAV → no trade, ever. The agent never invents a price.

About & honest limitations

  • What this is: a testnet demo for the Base Stocks Maxxing Builder Quest (Agentic Stock Finance track). It researches real tokenized-stock reference data and paper-trades it with full transparency.
  • What it is not: a broker, an exchange, or investment advice. No real stocks are bought or sold. Paper trades execute at NAV reference prices, not market prices.
  • Traction: this project launched 17 Nov 2026 and currently has zero real users — any usage numbers shown are this demo's own paper activity only.
  • Testnet only: all onchain activity is on Base Sepolia (chain 84532). Testnet ETH has no value. The B20 tokenized stocks themselves live on Base mainnet; this demo never touches mainnet.
  • US exclusion: trading is disabled for users located in the United States (IP geolocation check + self-attestation), because Coinbase tokenized stocks are not available to U.S. persons.
  • Open source: contract, agent rules, and this UI are public on GitHub (MIT). Builder Code bc_sijyqbvn registered for the agent wallet 0x822bbE7174FC3E54cc278AD35dDE6532b2F8415B.
